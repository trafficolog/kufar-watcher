# v0.2.0 — Контракт площадки

Source/development milestone, закрывающий delivery slice `0.2.0` из ROADMAP.

## Что вошло

- live reconnaissance electronics (`1.0.1`) с dated raw fixtures;
- live reconnaissance real estate (`1.0.2`) с dated raw fixtures;
- подтверждён общий search endpoint
  `api.kufar.by/search-api/v2/search/rendered-paginated`;
- подтверждена общая cursor pagination-механика через
  `pagination.pages[label=next].token`;
- electronics: `/count`, negotiable-price semantics, detail availability и
  embedded `__NEXT_DATA__` evidence;
- real estate: verified sale/apartment/Минск request shape, field delta и общий
  detail endpoint;
- подтверждено, что запланированный `SourceAdapter.page(query, cursor)` подходит
  обеим вертикалям;
- текущий platform-global `Listing.listId` остаётся обоснованным наблюдаемым
  контрактом; composite-key migration не потребовалась.

## Politeness / safety

Recon выполнялся последовательно. После `403` первая real-estate сессия была
немедленно остановлена; обход ограничений, proxy/VPN, IP rotation, fingerprint
spoofing и параллельный crawl не применялись.

## Verification

Финальный task PR `1.0.2` прошёл GitHub Actions verify run #203: documentation
consistency, tests/self-check, typecheck, lint, formatting, PostgreSQL
integration, build и оба Electron smoke завершились успешно.

Release PR `chore(release): 0.2.0` должен пройти тот же verification pipeline;
после merge этот файл обновляется только если фактический release commit или
verification расходятся с записанными данными.
