# 1.2.1 Global Kufar Rate Limiter Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add one FIFO, concurrency-1 worker-process rate limiter that spaces all future Kufar request starts by the live 2–5 second aggregate cadence and exposes one production singleton for the HTTP client in `1.2.2`.

**Architecture:** Implement a small `RateLimiter` in the Electron utility-process worker. It serializes async callbacks on one internal promise chain, samples one discrete jitter value per gap, waits only for the remaining start-to-start delay, and keeps the chain alive after callback rejection. A module-level `kufarRateLimiter` instance carries production defaults; the class is exported only so isolated unit tests and later HTTP-client dependency injection can construct deterministic instances.

**Tech Stack:** TypeScript 6, Electron utility process, Vitest 5 fake timers, Node timers. No new runtime dependency.

**Spec:** `docs/superpowers/specs/2026-09-07-1-2-1-rate-limiter-design.md`

## Global Constraints

- Production cadence is global across all Kufar hosts: one request start every `2000..5000 ms`.
- Production configuration is `minIntervalMs = 2000`, `jitterMinMs = 0`, `jitterMaxMs = 3000`.
- Concurrency is exactly `1`; FIFO ordering is mandatory.
- The first operation may start immediately.
- Jitter is an inclusive integer millisecond range using `jitterMinMs + floor(r * (jitterMaxMs - jitterMinMs + 1))` for `r` in `[0, 1)`.
- Millisecond configuration values are finite non-negative integers and `jitterMaxMs >= jitterMinMs`.
- Invalid random-source output rejects only the affected scheduling call and does not poison the queue.
- No HTTP, retries, `429` handling, raw logging, host-specific lanes, or scheduler behavior in this task.
- Unit tests must use virtual time only; no wall-clock sleeps.
- Preserve RED → GREEN history as separate commits.

- [ ] **Step 3: Implement the minimal rate limiter**

Create `electron/worker/kufar-rate-limiter.ts` with the following shape:

```ts
export interface RateLimiterOptions {
  minIntervalMs: number
  jitterMinMs: number
  jitterMaxMs: number
  random?: () => number
}

export const KUFAR_RATE_LIMITER_DEFAULTS = {
  minIntervalMs: 2000,
  jitterMinMs: 0,
  jitterMaxMs: 3000,
} as const

function assertNonNegativeInteger(name: string, value: number): void {
  if (!Number.isFinite(value) || !Number.isInteger(value) || value < 0) {
    throw new RangeError(`${name} must be a finite non-negative integer`)
  }
}

function sleep(ms: number): Promise<void> {
  return new Promise((resolve) => setTimeout(resolve, ms))
}

export class RateLimiter {
  private readonly minIntervalMs: number
  private readonly jitterMinMs: number
  private readonly jitterMaxMs: number
  private readonly random: () => number
  private tail: Promise<void> = Promise.resolve()
  private lastStartedAt: number | null = null

  constructor(options: RateLimiterOptions) {
    assertNonNegativeInteger('minIntervalMs', options.minIntervalMs)
    assertNonNegativeInteger('jitterMinMs', options.jitterMinMs)
    assertNonNegativeInteger('jitterMaxMs', options.jitterMaxMs)
    if (options.jitterMaxMs < options.jitterMinMs) {
      throw new RangeError('jitterMaxMs must be greater than or equal to jitterMinMs')
    }

    this.minIntervalMs = options.minIntervalMs
    this.jitterMinMs = options.jitterMinMs
    this.jitterMaxMs = options.jitterMaxMs
    this.random = options.random ?? Math.random
  }

  schedule<T>(operation: () => Promise<T>): Promise<T> {
    const run = this.tail.then(() => this.run(operation))
    this.tail = run.then(
      () => undefined,
      () => undefined,
    )
    return run
  }

  private sampleDelayMs(): number {
    const randomValue = this.random()
    if (!Number.isFinite(randomValue) || randomValue < 0 || randomValue >= 1) {
      throw new RangeError('random source must return a finite number in [0, 1)')
    }

    const jitterRangeSize = this.jitterMaxMs - this.jitterMinMs + 1
    const jitterMs = this.jitterMinMs + Math.floor(randomValue * jitterRangeSize)
    return this.minIntervalMs + jitterMs
  }

  private async run<T>(operation: () => Promise<T>): Promise<T> {
    if (this.lastStartedAt !== null) {
      const delayMs = this.sampleDelayMs()
      const remainingMs = this.lastStartedAt + delayMs - Date.now()
      if (remainingMs > 0) await sleep(remainingMs)
    }

    this.lastStartedAt = Date.now()
    return operation()
  }
}

export const kufarRateLimiter = new RateLimiter(KUFAR_RATE_LIMITER_DEFAULTS)
```
