# 1.2.2 Kufar HTTP Client Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add the first worker-process Kufar HTTP client that routes every network attempt through the global limiter, applies explicit Undici timeouts, bounded exponential retries, typed error classification, and temporary global slowdown on `429`.

**Architecture:** Extend the existing `RateLimiter` with one temporary cooldown gate, then add `electron/worker/kufar-http-client.ts` as the sole policy boundary for Kufar GET requests. The client uses an explicit Undici `Agent`, consumes each response body inside the limiter-scheduled attempt, retries only network/timeout/`5xx` failures, returns discriminated results for all outcomes, and never performs fallback or persistence itself.

**Tech Stack:** TypeScript 6, Node 22 (`>=22 <23`), Electron worker process, Vitest 5 fake timers, npm 11.4.2, `undici@7.29.1`.

**Spec:** `docs/superpowers/specs/2026-09-07-1-2-2-http-client-design.md`

## Global Constraints

- Every actual HTTP attempt, including retries, passes through the existing global `kufarRateLimiter`.
- Existing production cadence remains `2–5` seconds aggregate across all Kufar hosts.
- `429` is never retried and never sent to fallback; it imposes a temporary global cooldown and returns a distinct typed result.
- Network errors, Undici timeout errors, and `5xx` are retryable with at most `3` attempts total.
- Retry backoff is `500 ms`, then `1_000 ms`; the retry is scheduled through the limiter only after the backoff wait.
- `4xx` except `429` is permanent and returns after one attempt.
- Unexpected non-`2xx` statuses, including `3xx`, are permanent `unexpected-http`.
- `Retry-After` accepts integer seconds or HTTP-date; missing/invalid/non-positive values use `60_000 ms`; final cooldown is clamped at `900_000 ms`.
- Production timeout defaults are `connect=10_000 ms`, `headers=15_000 ms`, `body=30_000 ms`.
- Response bodies are returned as raw `Uint8Array`; JSON/schema parsing belongs to adapters.
- The HTTP client does not write Prisma/`Run`, create `HealthEvent`, persist raw snapshots, implement fallback, or wire scheduler/runtime traversal lifecycle.
- The transport owns one explicit Undici `Agent`; do not call `setGlobalDispatcher()`.
- Only `GET` is supported in this increment.
- Automated tests never call live Kufar endpoints.
- Preserve tests-only RED and production GREEN as separate commits for each behavior slice.
- Use exact-SHA GitHub Actions evidence before calling the task complete.

- [ ] **Step 4: Implement the minimum cooldown gate**

Reuse the existing non-negative-integer validator and change only the scheduling gate:

```ts
export class RateLimiter {
  // existing fields stay unchanged
  private cooldownUntil = 0

  imposeCooldown(delayMs: number): void {
    assertNonNegativeInteger('cooldown delay', delayMs)
    this.cooldownUntil = Math.max(this.cooldownUntil, Date.now() + delayMs)
  }

  private async run<T>(operation: () => Promise<T>): Promise<T> {
    let earliestStartAt = this.cooldownUntil

    if (this.lastStartedAt !== null) {
      earliestStartAt = Math.max(
        earliestStartAt,
        this.lastStartedAt + this.sampleDelayMs(),
      )
    }

    const remainingMs = earliestStartAt - Date.now()
    if (remainingMs > 0) await sleep(remainingMs)

    this.lastStartedAt = Date.now()
    return operation()
  }
}
```

Do not change FIFO chaining, production cadence constants, singleton creation, or random sampling.

      ok: true
      status: number
      body: Uint8Array

}

  headersTimeoutMs: 15_000,

Implement the interfaces above and a module-private transport:

```ts
class UndiciKufarTransport implements KufarTransport {
  private readonly agent = new Agent({
    connectTimeout: KUFAR_HTTP_DEFAULTS.connectTimeoutMs,
    headersTimeout: KUFAR_HTTP_DEFAULTS.headersTimeoutMs,
    bodyTimeout: KUFAR_HTTP_DEFAULTS.bodyTimeoutMs,
  })

  async request(input: KufarTransportRequest): Promise<KufarTransportResponse> {
    const result = await undiciRequest(input.url, {
      method: input.method,
      headers: input.headers,
      dispatcher: this.agent,
    })

    const headers: KufarHeaders = {}
    for (const [name, value] of Object.entries(result.headers)) {
      if (value !== undefined) headers[name] = value
    }

    return {
      status: result.statusCode,
      headers,
      body: new Uint8Array(await result.body.arrayBuffer()),
    }
  }

  async close(): Promise<void> {
    await this.agent.close()
  }
}
```

Production construction uses `new UndiciKufarTransport()` and `kufarRateLimiter`; tests inject substitutes. `get()` parses `string | URL`, calls exactly one `limiter.schedule(() => transport.request(...))`, returns the raw success union for `2xx`, and temporarily maps other statuses to permanent `unexpected-http` until Task 3. `close()` delegates to transport.

const getErrorCode = (error: unknown): string | null => {

    return error.code

- [ ] **Step 4: Implement the request-attempt loop**

The loop must satisfy this order:

1. `await limiter.schedule(() => transport.request(...))` for every attempt.
2. Transport throw: classify timeout/network; retry if attempts remain, otherwise return `temporary` with `status: null`.
3. `2xx`: return success immediately.
4. `5xx`: retry if attempts remain, otherwise return `temporary/http-5xx` with the last status.
5. non-429 `4xx`: return `permanent/http-4xx` immediately.
6. non-429 remaining status such as `3xx`: return `permanent/unexpected-http` immediately.
7. leave `429` as a non-retried temporary placeholder until Task 4; it must never enter the retry branch.

Retry delay is calculated exactly as:

```ts
this.retryBaseDelayMs * 2 ** (attempt - 1)
```

with default calls `[500, 1000]` before attempts 2 and 3.

- [ ] **Step 4: Implement Retry-After parsing**

```ts
const parseRetryAfterMs = (
  rawValue: string | undefined,
  nowMs: number,
  defaultCooldownMs: number,
  maxCooldownMs: number,
): number => {
  let candidateMs = defaultCooldownMs

  if (rawValue !== undefined) {
    if (/^\d+$/.test(rawValue)) {
      const parsedMs = Number(rawValue) * 1000
      if (Number.isFinite(parsedMs) && parsedMs > 0) candidateMs = parsedMs
    } else {
      const parsedMs = Date.parse(rawValue) - nowMs
      if (Number.isFinite(parsedMs) && parsedMs > 0) candidateMs = parsedMs
    }
  }

  return Math.min(candidateMs, maxCooldownMs)
}
```
