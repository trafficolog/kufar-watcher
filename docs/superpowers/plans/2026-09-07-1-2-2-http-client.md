# 1.2.2 Kufar HTTP Client Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add the first worker-process Kufar HTTP client that routes every network attempt through the global limiter, applies explicit Undici timeouts, bounded exponential retries, typed error classification, and temporary global slowdown on `429`.

**Architecture:** Extend the existing `RateLimiter` with one temporary cooldown gate, then add `electron/worker/kufar-http-client.ts` as the sole HTTP policy boundary for Kufar GET requests. The client uses an explicit Undici `Agent`, consumes each response body inside the limiter-scheduled attempt, retries only network/timeout/`5xx` failures, returns discriminated results, and never performs fallback, scheduler retry, schema parsing, or persistence itself.

**Tech Stack:** TypeScript 6, Node `>=22 <23`, Electron worker process, Vitest 5 fake timers, npm 11.4.2, `undici@7.29.1`.

**Spec:** `docs/superpowers/specs/2026-09-07-1-2-2-http-client-design.md`

## Global Constraints

- Every actual HTTP attempt, including retries, passes through the existing global `kufarRateLimiter`.
- Existing production cadence remains `2–5` seconds aggregate across all Kufar hosts.
- `429` is never retried and never sent to fallback; it imposes a temporary global cooldown and returns a distinct typed result.
- Network errors, Undici timeout errors, and `5xx` are retryable with at most `3` attempts total.
- Retry backoff is `500 ms`, then `1_000 ms`; the retry is submitted to the limiter only after the backoff wait.
- `4xx` except `429` is permanent and returns after one attempt.
- Unexpected non-`2xx` statuses, including `3xx`, are permanent `unexpected-http`; Undici redirect following is explicitly disabled with `maxRedirections: 0`.
- `Retry-After` accepts integer seconds or HTTP-date; missing, invalid, or non-positive values use `60_000 ms`; final cooldown is clamped at `900_000 ms`.
- Production timeout defaults are `connect=10_000 ms`, `headers=15_000 ms`, `body=30_000 ms`; each is overrideable when constructing a test client.
- Response bodies are returned as raw `Uint8Array`; JSON/schema parsing belongs to adapters.
- The HTTP client does not write Prisma/`Run`, create `HealthEvent`, persist raw snapshots, implement fallback, or wire scheduler/runtime traversal lifecycle.
- The transport owns one explicit Undici `Agent`; do not call `setGlobalDispatcher()`.
- Only `GET` is supported in this increment.
- Automated tests never call live Kufar endpoints.
- Preserve tests-only RED and production GREEN as separate commits for each behavior slice.
- Use exact-SHA GitHub Actions evidence before calling the task complete.

```ts
export class RateLimiter {
  private cooldownUntil = 0

  imposeCooldown(delayMs: number): void {
    assertNonNegativeInteger('cooldown delay', delayMs)
    this.cooldownUntil = Math.max(this.cooldownUntil, Date.now() + delayMs)
  }

  private async run<T>(operation: () => Promise<T>): Promise<T> {
    let earliestStartAt = this.cooldownUntil

    if (this.lastStartedAt !== null) {
      earliestStartAt = Math.max(
        earliestStartAt,
        this.lastStartedAt + this.sampleDelayMs(),
      )
    }

    const remainingMs = earliestStartAt - Date.now()
    if (remainingMs > 0) await sleep(remainingMs)

    this.lastStartedAt = Date.now()
    return operation()
  }
}
```

Keep FIFO chaining, singleton creation, and the `2–5` second production cadence unchanged.

Implement the module-private transport:

```ts
class UndiciKufarTransport implements KufarTransport {
  private readonly agent: Agent

  constructor(options: UndiciKufarTransportOptions) {
    this.agent = new Agent({
      connectTimeout: options.connectTimeoutMs,
      headersTimeout: options.headersTimeoutMs,
      bodyTimeout: options.bodyTimeoutMs,
    })
  }

  async request(input: KufarTransportRequest): Promise<KufarTransportResponse> {
    const result = await undiciRequest(input.url, {
      method: input.method,
      headers: input.headers,
      dispatcher: this.agent,
      maxRedirections: 0,
    })

    const headers: KufarHeaders = {}
    for (const [name, value] of Object.entries(result.headers)) {
      if (value !== undefined) headers[name] = value
    }

    return {
      status: result.statusCode,
      headers,
      body: new Uint8Array(await result.body.arrayBuffer()),
    }
  }

  async close(): Promise<void> {
    await this.agent.close()
  }
}
```

- [ ] **Step 4: Implement the attempt loop in this order**

1. Increment actual attempt count.
2. `await limiter.schedule(() => transport.request(...))` for every attempt.
3. Transport throw: classify timeout/network; retry if attempts remain, otherwise return `temporary` with `status: null`.
4. `2xx`: return success immediately.
5. `429`: do not retry; return a temporary non-retried placeholder only until Task 4 replaces it with the final rate-limit branch.
6. `5xx`: retry if attempts remain, otherwise return `temporary/http-5xx` with the last status.
7. non-429 `4xx`: return `permanent/http-4xx` immediately.
8. remaining status such as `3xx`: return `permanent/unexpected-http` immediately.

Retry delay is exactly:

```ts
this.retryBaseDelayMs * 2 ** (attempt - 1)
```

which yields `500` before attempt 2 and `1_000` before attempt 3 with defaults.

- [ ] **Step 3: Implement case-insensitive header lookup and Retry-After parsing**

```ts
const getHeader = (headers: KufarHeaders, name: string): string | undefined => {
  const wanted = name.toLowerCase()
  for (const [headerName, value] of Object.entries(headers)) {
    if (headerName.toLowerCase() !== wanted) continue
    return Array.isArray(value) ? value[0] : value
  }
  return undefined
}

const parseRetryAfterMs = (
  rawValue: string | undefined,
  nowMs: number,
  defaultCooldownMs: number,
  maxCooldownMs: number,
): number => {
  let candidateMs = defaultCooldownMs

  if (rawValue !== undefined) {
    if (/^\d+$/.test(rawValue)) {
      const parsedMs = Number(rawValue) * 1000
      if (Number.isFinite(parsedMs) && parsedMs > 0) candidateMs = parsedMs
    } else {
      const parsedMs = Date.parse(rawValue) - nowMs
      if (Number.isFinite(parsedMs) && parsedMs > 0) candidateMs = parsedMs
    }
  }

  return Math.min(candidateMs, maxCooldownMs)
}
```
