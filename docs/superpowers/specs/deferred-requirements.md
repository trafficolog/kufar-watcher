# Spec — отложенные требования (Post-MVP)

Требования, согласованные с пользователем, но сознательно вынесенные за пределы
релиза `1.0.0`. Документ существует, чтобы они не потерялись: договорённость,
которой нет в дереве задач, через полгода перестаёт существовать.

**Терминология.** Это Post-MVP. Не «фаза 2»: Фаза 2 в этом дереве означает
правила, матчинг и планировщик.

## Переписка с продавцом при участии ИИ

Согласовано на этапе опроса, ответы №29–31.

| Требование | Формулировка |
|-----------|--------------|
| Стартовое сообщение | заготовка, заданная в настройках монитора, дополняется деталями конкретного объявления |
| Цель диалога | уточнить состояние товара; договориться о пересылке, если продавец в другом городе; обсудить возможность торга; договориться о времени и месте просмотра, если продавец в городе пользователя |
| Город пользователя | берётся из глобальных настроек и определяет ветку диалога |
| Режим работы | **только human-in-the-loop**: агент готовит черновик, пользователь подтверждает отправку одной кнопкой |
| Прозрачность | явная маркировка того, что сообщение подготовлено с помощью ИИ |
| Системный промпт | глобальный, с возможностью переопределения на уровне монитора |

### Риски, зафиксированные при обсуждении

Переписка требует работы под аккаунтом пользователя, что качественно меняет
профиль риска по сравнению с чтением публичной выдачи: под угрозой сам аккаунт.
Плюс вопрос честности перед собеседником, который не знает, что говорит с ботом.
Оба риска обсуждались и приняты, отсюда обязательные human-in-the-loop и
маркировка.

Перед реализацией провести полный разбор угроз: поверхность атаки на этом шаге
меняется принципиально.

### Замечание по каналу

Не фиксировать архитектурно, что канал доставки сообщений — обязательно
внутренний API мессенджера площадки. У Kufar существуют официальные интеграции
сообщений для партнёрских систем, и на момент реализации картина может
отличаться от сегодняшней. Абстракцию канала при этом сейчас не проектировать:
интерфейс под неизвестный канал за год до реализации — спекулятивная работа.
Достаточно того, что требования записаны.

## Прочее отложенное

| Что | Почему отложено |
|-----|-----------------|
| Конструктор фильтров по таксономии категорий | в MVP ввод только готовой ссылкой; требует загрузки и хранения таксономии |
| Регулярные выражения в ключевых словах | простых слов и масок достаточно для заявленных сценариев |
| Несколько ссылок в одном мониторе | сводится к нескольким мониторам |
| Правила по цене на всех находках | по решению пользователя цена отслеживается только у помеченных объявлений |
| Автоматическое предложение патча при дрейфе схемы | принято решение ограничиться детектом и отчётом |
| Разбор DOM как третий уровень деградации | двух уровней достаточно |
| Другие площадки | низкая популярность в интересующих категориях; при необходимости — отдельный проект |
| Категория «Авто» | прямо исключена пользователем из зоны интересов |
