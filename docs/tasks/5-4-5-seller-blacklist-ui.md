# Задача 5.4.5 — Управление чёрным списком продавцов

> Эпик 5.4 · Фаза 5 · ⬜ todo · зависит от: 0.3.4 · оценка: 3-4 ч

## Цель

Дать интерфейс списку продавцов, который правила уже применяют.

## Контекст

Функциональный пробел, найденный на обзоре прототипов. Редактор правила
предлагает флажок «Применять чёрный список» и сообщает «сейчас в нём 4
продавца», но посмотреть этих четверых и убрать лишнего негде ни на одном
экране. Требование исключать продавцов персонально было в исходной постановке.

Отдельный пункт меню заводить не нужно: список смотрят редко и обычно из
редактора правила. Место — раздел настроек с якорем, на который ссылается
подпись флажка.

## Что должно быть сделано

- Секция в настройках с якорем `#seller-blacklist`
- Список: идентификатор или название, заметка «за что», дата добавления
- Добавление по идентификатору из адреса профиля или названию компании
- Удаление с отменой: действие обратимо, значит тост, а не вопрос
- Отказ на попытку добавить того, кто уже в списке
- Пустое состояние, объясняющее, зачем список нужен
- Ссылка «управлять» из подписи флажка в редакторе правила

## Критерии приёмки

- [ ] Четыре продавца из подписи флажка видны и удаляемы
- [ ] Ссылка из редактора правила открывает раздел и прокручивает к нему
- [ ] Удаление можно отменить, пока тост на экране
- [ ] Повторное добавление того же продавца отклоняется с объяснением
- [ ] Список пуст — объяснено, что это значит

## Подсказки

- Фильтр «только частные лица» — не отсюда: он задаётся параметром ссылки

## Не делать

- Не заводить отдельный раздел в меню
- Не добавлять импорт списка из файла
