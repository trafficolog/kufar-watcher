# Задача 1.1.3 — Определение категории и хоста по URL

> Эпик 1.1 · Фаза 1 · ⬜ todo · зависит от: 1.1.1 · оценка: 2-3 ч

## Цель

По разобранному адресу определить, к какой категории относится правило и какой адаптер его обслуживает.

## Контекст

Электроника и недвижимость живут на разных хостах API. Выбор делается один раз при сохранении правила, а не на каждом обходе.

## Что должно быть сделано

- Реализовать сопоставление категории с адаптером
- Адрес из категории «Авто» отклонять с сообщением, что категория вне периметра
- Неизвестную категорию отклонять с явной ошибкой

## Критерии приёмки

- [ ] Адрес по электронике направляется в соответствующий адаптер
- [ ] Адрес по недвижимости направляется в свой адаптер
- [ ] Адрес по авто отклоняется с понятным сообщением
- [ ] Юнит-тесты на все три случая зелёные

- Общий контекст — в карточке эпика и в `docs/AGENTS.md`
