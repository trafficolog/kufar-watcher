# Задача 2.1.2 — Сопоставление glob-масок и литеральных термов

> Эпик 2.1 · Фаза 2 · ⬜ todo · зависит от: 2.1.1 · оценка: 3-4 ч

## Цель

TDD. Реализовать сопоставление терма с текстом: точное совпадение для обычного терма и маска для терма с `*`.

## Контекст

Это поведение, обещанное в срезе MVP-1 под словами «простые слова и маски». Маска должна работать предсказуемо и не превращаться в регулярное выражение: символы, значимые в регэкспах, обязаны экранироваться, иначе терм вроде `iphone (новый)` уронит сопоставление или найдёт не то.

## Что должно быть сделано

- Сначала тесты: терм без `*` находит только точный токен; `playstation*` находит `playstation`, `playstation5`, `playstationa`; `*pro` находит `macpro`; `*` внутри терма; несколько `*` в одном терме; терм со скобками, точкой и плюсом
- Реализовать компиляцию терма в предикат: без `*` — сравнение нормализованных токенов, с `*` — маска
- Экранировать все спецсимволы регулярных выражений при компиляции маски
- Маска сопоставляется с токеном целиком, а не с его частью

## Критерии приёмки

- [ ] Все случаи из тестов проходят
- [ ] Терм со спецсимволами регэкспа не роняет сопоставление и не расширяет его
- [ ] Терм без `*` не находит словоформы: `колонка` не находит `колонки` — в MVP-1 это ожидаемое поведение
- [ ] Тесты написаны до реализации

## Подсказки

- Версионная таблица поведения термов — в `docs/superpowers/specs/matching-rules.md`

## Не делать

- Не поддерживать `?` и символьные классы: обещаны только `*`
- Не реализовывать морфологию
