# Задача 5.0.4 — Приёмка среза MVP-1

> Эпик 5.0 · Фаза 5 · ⬜ todo · зависит от: 5.0.3, 5.0.2, 3.2.3 · оценка: 2-3 ч

## Цель

Пройти сквозной сценарий на реальной ссылке и зафиксировать, что срез готов.

## Контекст

Точка, ради которой строился весь срез. Приёмка проверяет не отдельные задачи, а то, что цепочка работает целиком в руках пользователя, а не в тестах.

## Что должно быть сделано

- Пройти сценарий вручную на чистом профиле данных приложения (пустая база,
  пустое хранилище секретов): ввести токен, привязать чат, создать монитор по
  реальной ссылке, дождаться нового объявления, получить уведомление, открыть
  его кнопкой
- Проверить холодный старт: создание монитора не порождает пачку уведомлений о старых объявлениях
- Проверить перезапуск приложения посреди работы: расписания восстанавливаются, ни одна находка не потеряна
- Оставить два монитора на несколько часов и сверить полученные уведомления с выдачей вручную
- Записать результат в чек-лист приёмки и завести карточки на найденные дефекты

## Критерии приёмки

- [ ] Сценарий проходится полностью без обращения к базе и файлам
- [ ] Ни одного пропуска за время наблюдения
- [ ] Дубли, если появились, объяснимы записью в журнале о повторной отправке из неопределённого состояния
- [ ] Перезапуск приложения не нарушает работу
- [ ] Чек-лист заполнен, дефекты заведены

## Подсказки

- Общий контекст — в карточке эпика и в `docs/AGENTS.md`

## Не делать

- Не проверять тихие часы, сон машины, избранное и цены: они не входят в этот срез
- Не проверять установку на чистой машине: установочных пакетов до `5.7` не существует
- Не автоматизировать этот прогон: e2e-сценарии — задача `5.6.1`
