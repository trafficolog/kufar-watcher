# Задача 5.0.4 — Приёмка среза MVP-1

> Эпик 5.0 · Фаза 5 · ⬜ todo · зависит от: 5.0.3, 5.0.2, 3.2.3 · оценка: 2-3 ч

## Цель

Пройти два сквозных сценария на реальных ссылках — один для электроники и один
для недвижимости — и зафиксировать, что весь заявленный MVP-category perimeter
готов.

## Контекст

Точка, ради которой строился весь срез. Приёмка проверяет не отдельные задачи, а то, что цепочка работает целиком в руках пользователя, а не в тестах.

Релиз `1.0.0` гарантирует поддержку только двух подтверждённых verticals:
электроника через existing electronics adapter и недвижимость через existing
real-estate adapter. Прохождение сценария только по одной категории не закрывает
эту задачу и не должно интерпретироваться как поддержка остальных категорий
Kufar.

## Что должно быть сделано

- Пройти сценарий вручную на чистом профиле данных приложения (пустая база,
  пустое хранилище секретов): ввести токен, привязать чат, создать один монитор
  по реальной ссылке электроники и один монитор по реальной ссылке
  недвижимости, дождаться нового объявления в каждом сценарии, получить
  уведомление и открыть его кнопкой
- Проверить холодный старт для обеих поддерживаемых verticals: создание каждого
  монитора не порождает пачку уведомлений о старых объявлениях
- Проверить перезапуск приложения с обоими активными мониторами: расписания
  восстанавливаются, ни одна находка не потеряна
- Оставить два монитора на несколько часов — ровно по одному на электронику и
  недвижимость — и сверить полученные уведомления с соответствующей выдачей
  вручную
- Записать результат в чек-лист приёмки отдельно по каждой vertical и завести
  карточки на найденные дефекты

## Критерии приёмки

- [ ] End-to-end сценарий полностью проходится без обращения к базе и файлам
      отдельно для электроники и отдельно для недвижимости
- [ ] За время наблюдения нет пропусков ни у electronics-монитора, ни у
      real-estate-монитора
- [ ] Дубли, если появились, объяснимы записью в журнале о повторной отправке из неопределённого состояния
- [ ] Перезапуск приложения не нарушает работу ни одного из двух активных
      мониторов
- [ ] Чек-лист содержит использованные реальные ссылки и отдельный результат по
      каждой из двух поддерживаемых verticals; дефекты заведены
- [ ] Результат приёмки не расширяет обещание поддержки на другие категории
      Kufar без отдельного recon/contract evidence

## Не делать

- Не проверять тихие часы, сон машины, избранное и цены: они не входят в этот срез
- Не проверять установку на чистой машине: установочных пакетов до `5.7` не существует
- Не автоматизировать этот прогон: e2e-сценарии — задача `5.6.1`
- Не экстраполировать успешную приёмку electronics/real-estate на другие
  категории Kufar; категория «Авто» явно вне периметра
