# Задача 1.2.2 — Клиент: таймауты, ретраи, обработка ошибок

> Эпик 1.2 · Фаза 1 · ⬜ todo · зависит от: 1.2.1 · оценка: 3-4 ч

## Цель

Сетевой клиент поверх лимитера: таймауты, ретраи с экспоненциальной задержкой, различение временных и постоянных ошибок.

## Контекст

Сеть на домашней машине нестабильна: смена сети, засыпание, обрывы. Временный сбой не должен выглядеть как поломка площадки, а поломка площадки не должна маскироваться бесконечными ретраями.

## Что должно быть сделано

- Реализовать клиент на undici с таймаутами соединения и ответа
- Ретраи с экспоненциальной задержкой для сетевых ошибок и `5xx`; количество попыток ограничено
- Ответ `429` — увеличить паузу лимитера, снизить частоту, вернуть управление с
  пометкой и записать событие здоровья. Ретраи и переход на фолбэк при `429`
  запрещены: это обход только что выставленного ограничения
- Ошибки `4xx`, кроме `429`, считать постоянными и не ретраить
- Возвращать структурированный результат с классификацией исхода, а не бросать голое исключение

## Критерии приёмки

- [ ] Временный сбой сети приводит к успеху после ретрая
- [ ] Постоянная ошибка возвращается сразу, без исчерпания попыток
- [ ] Ответ `429` приводит к снижению темпа и явному сигналу наверх
- [ ] Все запросы проходят через лимитер из `1.2.1`
