# Задача 1.1.1 — Разбор URL листинга в CanonicalQuery

> Эпик 1.1 · Фаза 1 · ✅ done · зависит от: 0.1.3, 1.0.2 · оценка: 4-5 ч

## Цель

TDD. Превратить адрес отфильтрованной выдачи kufar.by в структуру `CanonicalQuery`.

## Контекст

Единственный способ ввода — вставка готовой ссылки. Значит, разбор адреса и есть интерфейс продукта: ошибка здесь означает, что пользователь мониторит не то, что думает. Функция чистая, детерминированная и не требует сети — идеальный кандидат на тесты вперёд кода.

## Что должно быть сделано

- Описать тип `CanonicalQuery`: категория, поисковая строка, регион, тип продавца, сортировка, прочие параметры
- Сначала тесты в `tests/unit/url-parse.test.ts` на наборе реальных адресов: с поисковой строкой, с регионом, без региона, с сегментом «без посредников», с категорийными параметрами
- Реализовать разбор пути и строки запроса
- Неизвестные параметры сохранять как есть, а не отбрасывать: они уйдут в запрос без изменений
- Нераспознаваемый адрес — явная ошибка с указанием причины, не молчаливое пустое правило

## Критерии приёмки

- [x] Все тестовые адреса разбираются корректно
- [x] Неизвестные параметры сохраняются в структуре
- [x] Адрес не с kufar.by отклоняется с внятной ошибкой
- [x] Тесты написаны до реализации, что видно по истории коммитов
