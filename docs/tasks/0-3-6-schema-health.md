## Цель

Добавить миграцией сущности `HealthEvent`, `SchemaSnapshot`.

## Контекст

Детект дрейфа и журнал здоровья нужны эпикам `4.1`–`4.3`. До этого события здоровья пишутся в `Run`, как описано в спецификации доменной модели.

Задача лежит в фазе 0 по принадлежности (это схема данных), но выполняется в
срезе `0.6.0`, а не в фундаменте. Номер задачи не равен порядку работ.

## Что должно быть сделано

- Добавить сущности `HealthEvent`, `SchemaSnapshot` по спецификации доменной модели
- Добавить относящиеся к ним индексы из спеки
- При появлении `HealthEvent` перевести на неё запись событий, которые до этого шли в `Run`
- Сгенерировать миграцию поверх текущего состояния схемы

## Критерии приёмки
