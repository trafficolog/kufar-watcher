# Задача 3.2.1 — Шаблон сообщения и экранирование

> Эпик 3.2 · Фаза 3 · ⬜ todo · зависит от: 3.1.3, 2.2.2 · оценка: 2-3 ч

## Цель

Собрать текст уведомления из данных объявления, безопасно для разметки Telegram.

## Контекст

Заголовки объявлений — недоверенный текст с площадки. Неэкранированный спецсимвол ломает разметку сообщения, а в худшем случае позволяет чужому тексту выдать себя за часть интерфейса бота.

## Что должно быть сделано

- Реализовать шаблон: имя монитора, заголовок, цена, регион, ссылка, фрагмент описания при наличии
- Корректно отображать договорную цену, а не пустое место
- Экранировать все спецсимволы разметки в данных с площадки
- Обрезать сообщение, если оно превышает лимит длины Telegram
- Покрыть юнит-тестами: спецсимволы в заголовке, договорная цена, отсутствующий регион, длинный заголовок

## Критерии приёмки

- [ ] Заголовок со спецсимволами разметки не ломает сообщение
- [ ] Договорная цена отображается словами
- [ ] Сообщение никогда не превышает лимит длины
- [ ] Юнит-тесты зелёные
