# Задача 5.8.1 — Доска наблюдения

> Эпик 5.8 · Фаза 5 · ⬜ todo · зависит от: 5.5.3, 5.0.3 · оценка: 6-8 ч

## Цель

Главный экран: состояние всех мониторов на одной шкале времени, последние
находки и то, что требует решения.

## Контекст

До этой задачи у прототипа `kufar-board.html` не было исполнителя: эпики фазы 5
покрывали список правил, ленту, здоровье и приёмку, но не саму доску. Экран
существовал в макете и обещался дорожной картой, при этом ни одна карточка не
должна была его построить.

Доска приходит в срезе `1.0.0`, а не в MVP: до неё роль обзора выполняет
минимальный список правил из `5.0.3`.

## Что должно быть сделано

- Общая шкала времени и дорожки по монитору: отметки позиционируются в процентах,
  чтобы дорожка читалась на любой ширине окна
- Отметки различаются формой и высотой, а не только цветом: обход, находка, сбой,
  остановка
- Ключ к отметкам рядом с заголовком: форма штрихов сама по себе ничего не говорит
- Каждой дорожке — текстовое описание для чтения без зрения
- Блок «требует решения»: остановленные мониторы с переходом в раздел здоровья
- Отметка деградации адаптера со ссылкой на подробности
- Пауза всех мониторов с подтверждением и отменой
- Последние находки с переходом в ленту

## Критерии приёмки

- [ ] Молчащий монитор виден на дорожке без чтения журнала
- [ ] Дорожка не схлопывается при ширине окна 320 пикселей
- [ ] Состояние отметки различимо без различения цвета
- [ ] Каждая дорожка имеет осмысленное текстовое описание
- [ ] Пауза всех останавливает счётчик следующего обхода и отражается на дорожках
- [ ] Работа адаптера через запасной канал видна, не заходя в раздел здоровья
