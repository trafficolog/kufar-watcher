# Задача 3.1.1 — Бот на grammY и привязка чата

> Эпик 3.1 · Фаза 3 · ✅ done · зависит от: 0.1.2 · оценка: 3-4 ч

## Цель

Поднять бота на long-polling и связать его с единственным разрешённым чатом.

## Контекст

Вебхук невозможен: у домашней машины нет постоянного адреса. Привязка к одному чату — не только удобство, но и защита: бот, отвечающий любому, кто его нашёл, отдаёт посторонним содержимое чужих мониторов.

Отсюда следует, что привязывать первый написавший чат автоматически нельзя. Имя бота угадываемо, и тот, кто напишет раньше хозяина, получит поток его находок — с адресами, ценами и городом. Поэтому связь между человеком за приложением и чатом должна быть доказана действием в самом приложении, а не фактом сообщения.

Достаточно простейшей формы: сообщение делает чат кандидатом, приложение показывает, кто это, человек нажимает «Привязать». Вариант с одноразовым кодом в `/start <код>` тоже годится и удобнее, но для персонального приложения подтверждение кнопкой закрывает риск полностью.

## Что сделано

- grammY long-polling работает в utility worker через отдельный adapter/service boundary.
- Первое сообщение сохраняет только in-memory кандидата; привязка пишется в `Setting` исключительно после явного подтверждения из Electron main.
- Renderer получает только безопасный `TelegramDesktopState` и `bindCandidate()` без аргументов; `chatId` для подтверждения выбирает main из текущего кандидата, поэтому renderer не может запросить привязку произвольного чата.
- После привязки сообщения и callback-и из других чатов игнорируются молча.
- Токен читается Electron main через `safeStorage`, не попадает в worker argv/env, renderer DTO и journal; Linux `basic_text` трактуется как незащищённое хранилище.
- Supervisor хранит конфигурацию только в памяти, replay-ит её после restart worker и коррелирует bind-ответы по `requestId`.
- Отсутствующий или недоступный защищённый secret переводит Telegram в отключённое состояние вместо падения worker.

## Критерии приёмки

- [x] Бот принимает команды только из привязанного чата
- [x] Чат, написавший боту, не получает находок до подтверждения в приложении
- [x] Подтверждение доступно только в окне приложения, не из переписки
- [x] Сообщение из чужого чата игнорируется молча
- [x] Отсутствие токена не роняет воркер
- [x] Токен не появляется в журнале ни на одном уровне
