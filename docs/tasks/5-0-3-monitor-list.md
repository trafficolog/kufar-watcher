# Задача 5.0.3 — Минимальный список мониторов

> Эпик 5.0 · Фаза 5 · ⬜ todo · зависит от: 5.0.1, 2.4.3 · оценка: 3-4 ч

## Цель

Список правил с состоянием, временем последнего обхода и результатом.

## Контекст

Пользователю нужно одно место, куда посмотреть, когда уведомлений долго нет: работает ли монитор, когда он ходил в последний раз, чем закончилось. Без этого молчание системы неотличимо от отсутствия новых объявлений — то есть от главного дефекта такой системы.

## Что должно быть сделано

- Список: имя, интервал, состояние, время последнего обхода, его исход
- Кнопки приостановить и возобновить монитор
- Показывать состояние канала Telegram и подключения к базе
- Обновлять данные по событиям из воркера, без опроса по таймеру

## Критерии приёмки

- [ ] Состояние каждого монитора видно без открытия базы
- [ ] Неуспешный последний обход виден с причиной
- [ ] Приостановка снимает расписание, возобновление возвращает
- [ ] Список обновляется при завершении обхода
