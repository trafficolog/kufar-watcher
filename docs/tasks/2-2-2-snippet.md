# Задача 2.2.2 — Извлечение фрагмента вокруг совпадения

> Эпик 2.2 · Фаза 2 · ⬜ todo · зависит от: 2.2.1 · оценка: 2-3 ч

## Цель

Вернуть короткий фрагмент текста вокруг найденного терма для вставки в уведомление.

## Контекст

Фрагмент нужен, чтобы пользователь понимал, почему объявление пришло. В MVP-1 поиск идёт по заголовку, и фрагмент чаще всего совпадает с ним целиком; модуль всё равно пишется сейчас, потому что с приходом поиска по описанию он становится обязательным, а его интерфейс влияет на форматтер сообщения.

## Что должно быть сделано

- Реализовать вырезку фрагмента заданной длины вокруг позиции совпадения, по границам слов
- Не возвращать фрагмент, если совпадение в заголовке и заголовок целиком короче лимита: дублировать его в сообщении незачем
- Обрезку обозначать многоточием с обеих сторон, где она произошла
- Покрыть юнит-тестами: совпадение в начале, в середине, в конце, несколько совпадений

## Критерии приёмки

- [ ] Фрагмент не разрывает слова
- [ ] Совпадение в коротком заголовке фрагмента не порождает
- [ ] Несколько совпадений дают один фрагмент вокруг первого
- [ ] Юнит-тесты зелёные

## Подсказки

- Общий контекст — в карточке эпика и в `docs/AGENTS.md`

## Не делать

- Не подсвечивать совпадение разметкой: это решает форматтер в `3.2.1`
