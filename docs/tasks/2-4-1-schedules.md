# Задача 2.4.1 — Регистрация расписаний pg-boss

> Эпик 2.4 · Фаза 2 · ⬜ todo · зависит от: 0.3.1 · оценка: 3-4 ч

## Цель

Регистрировать отдельное расписание для каждого включённого монитора.

## Контекст

Мониторов около пяти, поэтому нет смысла строить общий диспетчер. pg-boss уже умеет расписания и хранит их в той же PostgreSQL — один механизм вместо собственного таймера и отдельного состояния.

## Что должно быть сделано

- При старте загрузить включённые мониторы и зарегистрировать schedule для каждого
- При создании, изменении интервала, включении и выключении обновлять schedule
- Имя задачи стабильно связано с id монитора
- Обработчик запускает ровно один обход этого монитора

## Критерии приёмки

- [ ] После старта для каждого enabled-монитора есть schedule
- [ ] Изменение интервала обновляет расписание без дублей
- [ ] Отключённый монитор не запускается
- [ ] Перезапуск приложения не создаёт вторых расписаний

## Подсказки

- Общий контекст — в карточке эпика и в `docs/AGENTS.md`

## Не делать

- Не строить центральный tick-loop
- Не менять интервалы автоматически — эпик 4.2
