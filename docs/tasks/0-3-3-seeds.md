# Задача 0.3.3 — Сиды и dev-фикстуры

> Эпик 0.3 · Фаза 0 · ⬜ todo · зависит от: 0.3.2 · оценка: 2 ч

## Цель

Наполнить базу набором данных, на котором можно разрабатывать и прогонять интеграционные тесты без обращения к площадке.

## Контекст

Ни один автотест не ходит в сеть. Значит, нужны правдоподобные данные локально — иначе разработка следующих фаз упрётся в ручное наполнение базы через SQL.

## Что должно быть сделано

- Написать скрипт сидов: два монитора, набор объявлений, несколько совпадений, одно избранное с историей цен
- Добавить хелпер поднятия чистой базы для интеграционных тестов
- Добавить npm-скрипты `db:seed` и `db:reset`

## Критерии приёмки

- [ ] `npm run db:seed` наполняет базу и повторный запуск не падает
- [ ] Интеграционный тест получает изолированную базу
- [ ] Сиды не содержат реальных данных с площадки

- Общий контекст — в карточке эпика и в `docs/AGENTS.md`

## Не делать
