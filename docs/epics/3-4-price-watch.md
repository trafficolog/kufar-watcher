# Эпик 3.4 — Мониторинг цен избранного

## Цель

Помеченные объявления проверяются раз в час. При архивации монитора его избранное замораживается.

Два допущения, которые надо назвать допущениями. Первое: час — продуктовый выбор по умолчанию, а не измеренная величина; менять его следует по опыту эксплуатации, а не по ощущению. Второе, важнее: предположение, что тот же запрос отдаёт и цену, и статус объявления, взято из общей логики карточки и живым ответом не подтверждено. Строить расписание на «бесплатном статусе» до подтверждения нельзя — проверка входит в разведку `1.0.1`.
