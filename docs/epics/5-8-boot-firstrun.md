# Эпик 5.8 — Доска наблюдения и первый запуск

## Цель

Реализовать главный экран приложения в обоих его состояниях: когда правил ещё
нет и когда они работают.

## Контекст

Это один маршрут с двумя состояниями, а не два экрана. Доска с нулями ничего не
объясняет новому пользователю, поэтому при отсутствии правил тот же маршрут
показывает два шага до первого уведомления. Отдельный `/onboarding` создал бы
вторую навигационную систему ради одного показа.

Экрана инициализации здесь нет: он принадлежит задаче `0.2.3`, где уже описана
последовательность подъёма Docker и базы. Держать его в двух местах значит
сделать работу дважды.

## Планируемые задачи

- `5.8.1` — Доска наблюдения: дорожки обходов, лента находок, требующее решения
- `5.8.2` — Состояние первого запуска и переход к обычной доске

## Критерии приёмки эпика

- [ ] При отсутствии правил маршрут объясняет следующий шаг, а не показывает нули

- [ ] Начиная со среза `1.0.0` главным маршрутом становится доска наблюдения
