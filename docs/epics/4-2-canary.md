# Эпик 4.2 — Канарейка площадки

## Цель

Раз в час по **каждому адаптеру отдельно** выполняется широкий эталонный запрос с заведомо непустым результатом. Пустой ответ или сломанная структура означают поломку, а не отсутствие новых объявлений. Уведомление приходит только при поломке.

Канареек столько же, сколько независимых адаптеров: если электроника жива, а недвижимость сломалась, общая канарейка этого не увидит. Эталон — широкий запрос по категории, а не конкретное объявление: объявления на площадке автоматически деактивируются по истечении срока, и канарейка, привязанная к одному из них, однажды сломается сама по себе и научит игнорировать свои алерты.

## Планируемые задачи
