# Эпик 5.2 — Мониторы: список и редактор

## Цель

Список правил с состоянием и последним обходом. Редактор: ссылка, имя-тег, интервал, ключевые слова, поиск по описанию, фильтр продавца. Перед сохранением — предпросмотр количества объявлений.

Предпросмотр обязан быть подписан честно. `/count` знает только фильтры площадки и ничего не знает про морфологию, маски, исключения и чёрный список продавцов: это счёт **до** локальной фильтрации. Надпись «под правило попадает 123 объявления» была бы враньём, за которым пользователь не поймёт, почему уведомлений приходит вдесятеро меньше.

## Планируемые задачи

- `5.2.1` — Список мониторов с состоянием
- `5.2.2` — Редактор правила
- `5.2.3` — Предпросмотр: счёт площадки до локальных фильтров
- `5.2.4` — Live scheduler sync после редактирования монитора

> Карточки `5.2.1`–`5.2.3` детализируются перед стартом UI-фазы. Карточка
> `5.2.4` создана заранее по итогам повторного аудита фазы 2 как обязательный
